# Review and handoff

Compare the output with the brief, not just with the first mockup. Check that the
primary task is clear, real content fits, the selected language is coherent, and
the bold visual decision serves the subject. Remove unsupported claims and
decorative content that pretends to be information.

Render the design at relevant widths. Inspect typography, line breaks, crops,
overlap, scroll behavior, and contrast. Check visible focus and the primary
interaction. Verify states only where the feature has those states. Record
observations and screenshots in the artifact. State explicitly when a visual,
runtime, or accessibility check could not run.

Fix demonstrated problems and inspect the affected area again when needed.
Testing effort should match the risk. Do not perform arbitrary cycles to appear
thorough, and do not copy a source prompt’s fixed screenshot limit into this
workflow. The goal is a working, reviewable result.

Use `artifact finalize` to validate the planning records, local image analyses,
artboards, assembled canvas, and review evidence. The command cannot assess
artistic quality or prove that an agent honestly looked at an image. Human review
remains valuable. Deliver the actual artifact path or verified native artifact
link, explain material limits, and report what was checked without overclaiming.
