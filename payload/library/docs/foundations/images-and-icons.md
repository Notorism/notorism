# Images and icons

## Give an image a job

Use photography to show the actual subject, material, person, place, or product
when visual evidence helps. Use illustration to explain relationships or a
concept that photography cannot convey clearly. Use diagrams for mechanisms.
Do not place unrelated stock images into empty areas simply to make a layout
look finished. Whitespace can be the correct choice.

Record image source, creator where known, license or permission status, and
whether it is a photo, screenshot, authored study, or generated image. A public
URL is not a reuse license. Keep external reference links as links unless reuse
is permitted. Do not manufacture a real brand mark from memory.

For raster assets, supply intrinsic dimensions and meaningful crops. Keep the
subject clear at mobile widths. Provide responsive sizes and modern formats
when practical. Lazy-load below-the-fold images, not the primary visual. Avoid
layout shifts. Describe information-bearing imagery with useful alt text;
mark decorative images with an empty alternative.

## Use icons for recognition

Prefer the existing product’s icon set. Otherwise choose one consistent library
and respect its license. Keep stroke weight, filled versus outline treatment,
optical size, and alignment consistent. Icons should identify familiar actions
or states. A flower, sparkle, or bolt before every heading rarely adds meaning.

Use text labels for unfamiliar actions. Icon-only controls require an accessible
name, a visible focus state, and an adequate hit area. Tooltips supplement labels
rather than becoming the only way to identify an action. Do not substitute emoji,
dingbat characters, or arbitrary Unicode for a coherent icon system unless that
is explicitly part of the brand.

Small native vector diagrams and geometric assets can be authored as SVG. Use
proper graphics tools for elaborate illustration and real image-generation tools
when requested bitmap visuals need them. Do not claim a CSS sphere is a photo
or a physical simulation. Inspect generated imagery before using it.

## Read the local reference images

Each style includes three original PNG studies, their editable HTML, and metadata.
Inspect the PNGs with a tool that can actually display images. Open HTML demos
for interaction styles. Record what you see, which choices transfer, and which
ones should change for the current content. The studies are simplified teaching
examples, not screenshots of award-winning sites or historical artifacts.
