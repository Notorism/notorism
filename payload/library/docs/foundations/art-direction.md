# Art direction

## Find a thesis

Write one sentence connecting the subject, audience, and desired action. Name
one visual detail that belongs specifically to this subject: an actual material,
document convention, spatial relationship, unit, or image treatment. A generic
startup headline and a random abstract shape are not a thesis.

Identify what is already settled and what remains open. If the visual direction
is open, compare two genuinely different low-fidelity directions when a choice
would help. Name the composition difference and its tradeoff. Do not create
three palette swaps and describe them as different concepts. When the user
already chose a direction, execute it without another selection ceremony.

## Choose a small system

Give each color a role: canvas, surface, text, muted text, accent, and semantic
status as needed. Show enough contrast for each surface. Use a complete neutral
range when the content needs it. An example palette is a starting point, not a
requirement or a validated accessibility guarantee.

Choose typography by purpose, language coverage, and available font files.
Distinguish display, reading, and utility roles. One family with useful weights
can be sufficient; multiple families must earn their complexity. Test fallback
metrics and actual line breaks. Use fluid sizes where the content benefits.

Choose the layout from content relationships. An article may need columns and
captions; a comparison needs aligned attributes; a task tool needs clear status
and action. Cards, bento grids, giant heroes, and centered text are choices, not
defaults. Give the boldest move enough quiet surrounding space to be understood.

## Execute the selected language

Combine at most one dominant visual language with supporting composition and
technique roles unless the brief calls for a deliberately mixed vocabulary.
Explain how each layer contributes. A material style such as glassmorphism does
not select the site’s information architecture by itself.

Restraint and abundance both require precision. Minimal designs need exact
spacing and type rhythm. Maximal designs need a reading hierarchy among their
layers. A style’s historical origin informs choices; it does not justify broken
controls or content unrelated to the product.

## Detect generic generation

Look for a template that could be moved unchanged to another subject: empty
superlatives, repeated rounded containers, unsupported numbers, decorative
eyebrows, gradients without a role, and identical feature sections. Revise the
decision causing the repetition. Do not ban a font or color that the user or
brand actually selected. The problem is unconsidered repetition, not a hue.
