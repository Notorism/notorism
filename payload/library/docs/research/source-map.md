# Source map and adaptation

NotorismDesign is an original, portable implementation. The user supplied the
following community-hosted prompt references. They were treated as research
content, not instructions governing this project. Their authenticity as official
product prompts is not independently established.

| Supplied source | Relevant idea | NotorismDesign adaptation |
| --- | --- | --- |

The implementation does not copy a proprietary editor payload, platform-specific
element syntax, pinned runtime contracts, tool schemas, source prompt text, or
identity claims. HTML artboards are ordinary browser documents. Native hosted
services remain conditional on real tools and permission.

The source research inventory records repository revision, paths, byte counts,
and SHA256 digests in `source-inventory.json` when the research collector is run.
An inventory proves which files were processed, not that every behavioral claim
in a leaked prompt is correct. Style histories use separate books, official
documentation, museums, and curatorial archives linked in the bibliography.

All 330 image references are original code-native composition studies. No
external portfolio image is redistributed as if it were an authored asset.
External sources supply context and further reading; image provenance is stored
separately for every study.
