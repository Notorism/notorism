# Film Grain

## What this label means

Granularity associated with photographic film structure. Digital grain simulates texture without necessarily reproducing the chemical process.

Category: Texture and graphic techniques. This label describes a graphic treatment that can support different identities.

## Defining mechanics

- Fine grain.
- low intensity.
- image-local treatment.
- preserved contrast.

## Suitable subjects

Cinema exhibition, Photo archive, Travel journal are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #ded5c2, #34362e, #8a795d, #afa993. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.

## Main failure mode

Covering body text and controls with heavy noise. Other risks must be judged in the current brief rather than added as universal style bans.
