# Frutiger Metro

## What this label means

A curatorial label for colorful vector languages associated with 2000s digital culture. It relates to neighboring aesthetics of the period.

Category: Retro and alternative aesthetics. This entry supplies a visual vocabulary, not permission to change the user’s product or scope.

## Defining mechanics

- Silhouettes.
- curves.
- color fields.
- vectors.
- urban graphics.

## Suitable subjects

Community radio, Urban festival, Transit calendar are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #f0d63f, #25354c, #e76c9c, #39b6a1. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.

A simplified original composition study, not a historical specimen or a real-client website screenshot.

## Main failure mode

Putting Aero-style glass realism into every flat plane. Other risks must be judged in the current brief rather than added as universal style bans.
