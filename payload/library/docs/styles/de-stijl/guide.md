# De Stijl

## What this label means

A movement and journal begun in the Netherlands in 1917 with Theo van Doesburg and collaborators. Its vocabulary includes orthogonality and reduction.

Category: Art movements. This entry supplies a visual vocabulary, not permission to change the user’s product or scope.

## Defining mechanics

- Black grids.
- rectangles.
- primaries.
- balanced asymmetry.
- white planes.

## Suitable subjects

Object gallery, Architecture catalog, Composition course are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #f4f0e7, #171717, #b92e29, #1f56a2. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.

## Main failure mode

Turning a known painting into an interface or using primaries without a system. Other risks must be judged in the current brief rather than added as universal style bans.

The origin paragraph is a concise contextual introduction. Community labels may have disputed boundaries and no known founder. Distinguish a style’s history from the history of a curatorial archive.
