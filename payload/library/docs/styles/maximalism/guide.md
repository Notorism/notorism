# Maximalism

## What this label means

Abundance appears in many decorative and editorial traditions. The label does not identify one school with a universal founder.

Category: Interface and materials. This entry supplies a visual vocabulary, not permission to change the user’s product or scope.

## Defining mechanics

- Layered hierarchy.
- contrasting scales.
- coordinated patterns.
- purposeful color.

## Suitable subjects

Music festival, Pattern shop, Culture magazine are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #f5cc35, #2d1954, #e34276, #189287. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.

A simplified original composition study, not a historical specimen or a real-client website screenshot.

## Main failure mode

Treating abundance as random distribution without a focal point. Other risks must be judged in the current brief rather than added as universal style bans.
