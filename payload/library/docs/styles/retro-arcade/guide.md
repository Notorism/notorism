# Retro Arcade

## What this label means

Reinterprets cabinets and classic arcade games. Different decades offer distinct vocabularies from raster art to illuminated signage.

Category: Retro and alternative aesthetics. This entry supplies a visual vocabulary, not permission to change the user’s product or scope.

## Defining mechanics

- Vivid contrast.
- meaningful scores.
- pixels.
- game frame.
- direct action.

## Suitable subjects

Local tournament, Game library, Interactive museum are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #18213a, #f7db71, #db6f87, #65b9c9. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.

A simplified original composition study, not a historical specimen or a real-client website screenshot.

## Main failure mode

Gamifying service tasks without a benefit to the person. Other risks must be judged in the current brief rather than added as universal style bans.
