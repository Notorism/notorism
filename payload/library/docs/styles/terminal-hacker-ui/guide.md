# Terminal / Hacker UI

## What this label means

Inspired by real terminals and command-line interfaces. Hacker describes a visual metaphor here, not a malicious purpose.

Category: Retro and alternative aesthetics. This entry supplies a visual vocabulary, not permission to change the user’s product or scope.

## Defining mechanics

- Monospaced type.
- clear commands.
- prompts.
- readable output.
- state feedback.

## Suitable subjects

Search tool, Code archive, Research console are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #121d19, #d5e9d8, #86b293, #a6c1ad. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.

A simplified original composition study, not a historical specimen or a real-client website screenshot.

## Main failure mode

Low-contrast green text or invented commands that do nothing. Other risks must be judged in the current brief rather than added as universal style bans.
