# Mixed-Media Design

## What this label means

Combinations of media appear across artistic practices. Communication should articulate photography, type, and illustration through a clear thesis.

Category: Texture and graphic techniques. This label describes a graphic treatment that can support different identities.

## Defining mechanics

- Different materials.
- unifying element.
- scale contrasts.
- meaningful layers.

## Suitable subjects

Image festival, Art magazine, Research portfolio are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #e7d9c6, #3e3540, #a56a80, #708d86. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.

A simplified original composition study, not a historical specimen or a real-client website screenshot.

## Main failure mode

Adding effects with no role for each medium. Other risks must be judged in the current brief rather than added as universal style bans.
