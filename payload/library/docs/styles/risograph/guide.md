# Risograph

## What this label means

A stencil duplication process associated with RISO machines. Ink overlaps and imperfect registration can inspire explicitly identified digital simulations.

Category: Texture and graphic techniques. This label describes a graphic treatment that can support different identities.

## Defining mechanics

- Short palette.
- grain.
- overprinting.
- subtle offset.
- paper material.

## Suitable subjects

Independent publisher, Print workshop, City zine are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #efdfbe, #384559, #37688a, #ce7558. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.

## Main failure mode

Calling a filter actual printing or blurring operational content. Other risks must be judged in the current brief rather than added as universal style bans.
