# Neon Glow

## What this label means

A simulation of emitted light inspired by signage and luminous materials. Halos must preserve a readable core.

Category: Texture and graphic techniques. This label describes a graphic treatment that can support different identities.

## Defining mechanics

- Defined core.
- limited halo.
- dark base.
- hierarchical emission.

## Suitable subjects

Live venue, Night exhibition, Music calendar are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #132735, #e6f0ef, #63b5b0, #d895b5. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.

A simplified original composition study, not a historical specimen or a real-client website screenshot.

## Main failure mode

Blurring text and using glow as its only contrast. Other risks must be judged in the current brief rather than added as universal style bans.
