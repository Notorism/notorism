# Bento Grid

## What this label means

A contemporary bento-box metaphor for differently sized modules. The composition inherits grid techniques rather than defining a historic movement.

Category: Composition and layout. This label describes organization rather than a complete visual identity.

## Defining mechanics

- Varied modules.
- related proportions.
- one dominant focus.
- content sized by role.

## Suitable subjects

Product library, Research summary, Project portfolio are starting contexts for analysis. Choose this language only when the audience, content, and primary task support it. Explain which mechanic belongs to the subject.

## Implementation decisions

Use hierarchy and composition before decoration. Resolve the actual product’s existing tokens first. The study palette is #f1f0ea, #30382e, #6e8365, #d7c49c. Its roles are canvas, foreground, accent, and supporting surface. Measure actual contrast; the sample palette is not an accessibility certificate.

Keep reading text clear while applying the distinctive treatment to the appropriate visual plane. Match image material and icon weight to the direction. Preserve recognizable actions, semantic markup, focus, and responsive reading order. Move the layout to narrow screens intentionally rather than shrinking it.
